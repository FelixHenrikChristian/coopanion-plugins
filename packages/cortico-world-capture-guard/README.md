# 截图隐身

Coopanion 独立 World 插件，API 6，版本 1.1.0。所有设置只放在本插件的「配置」中。

默认使用 NVIDIA 即时重放兼容模式：平时照常显示桌宠，按截图快捷键时暂时隐藏，避免出现在截图里。要截桌宠时，打开：

**World 扩展 → 截图隐身 → 配置 → 允许截图包含桌宠**

完成后关闭该选项即可。保存配置后自动生效。

## NVIDIA 即时重放兼容

旧版使用 Windows 常驻捕获排除标志。NVIDIA 桌面录制会把这种窗口视为受保护内容，从而停止录制；直接改用另一种排除调用也不能保证避开此限制。

1.1.0 默认开启「兼容 NVIDIA 即时重放」。在此模式中，窗口的捕获标志始终为 0，截图时通过临时隐藏窗口实现，因此不会因本插件的保护标志阻止录制。截图时桌宠会从桌面短暂消失，录屏中平时会包含桌宠。

默认识别以下截图快捷键，不抢占或修改截图工具已有的按键：

- PrintScreen、Win+Shift+S
- Ctrl+Alt+A、Alt+A（微信 / QQ 常见设置）
- Ctrl+1（PixPin 默认）
- F1（Snipaste 默认）、Alt+F1（NVIDIA 截图）

若你的按键不同，在插件配置的「截图快捷键」中调整，以逗号分隔。通过截图工具的鼠标菜单发起截图不会触发临时隐藏；此时可先手动隐藏桌宠，或改用已配置的截图快捷键。

临时隐藏默认持续 10 秒，按 Esc 或 Enter 可提前恢复。已被手动隐藏的桌宠不会被自动显示。停用插件会移除按键监听并恢复由插件临时隐藏的桌宠。

如不使用 NVIDIA 即时重放，可关闭兼容模式，回到常驻系统排除：屏幕上始终显示，标准捕获接口不包含桌宠；但 NVIDIA 录制可能再次被阻止。

可选设置：

- **启动时恢复截图隐藏**：默认开启，防止下次启动忘记切回。
- **允许截取后自动恢复（秒）**：默认 0，表示手动切回；可设为 60 等时长。
- **截图时暂时隐藏（秒）**：兼容模式的隐藏时长，默认 10 秒。
- **截图快捷键**：只匹配截图按键，不保存或发送输入文字。

本插件不增加托盘菜单、原生页面按钮或模型工具，不注册或抢占全局快捷键。停用插件后恢复正常截图行为。

首次安装并启用后，需要重启一次 Coopanion 的 Core 进程，或完整退出并重新打开 Coopanion。

## 安装

包内附有 `install-local.cjs` 和 `install-local.cmd`。解压后双击 CMD，输入包含 Coopanion.exe 的安装目录；完成后重启 Core 进程。安装器会备份扩展清单和部署配置，并只添加本插件的条目。

本插件使用标准 `cortico-world-*` 包结构，可作为本地包注册。已经安装后，可在原有 World 扩展管理页启用、停用和删除。删除前先停用。

## 实现与兼容性

支持 Windows 10 2004 及以后版本，目前验证于本机 Coopanion 0.2.18。

通过桌宠 World 已有的 `CORTICO_DESKTOP_PET_HOST` 宿主入口启动独立窗口，复用原版 `runPetHost`、渲染页和预加载脚本。兼容模式在原有截图快捷键投递前隐藏窗口；只有明确关闭兼容模式时才设置捕获保护。原程序的主入口、托盘、原生设置页和桌宠源码均不修改。

独立宿主的运行库复用 Coopanion 已有文件：同一磁盘使用硬链接，跨磁盘时复制。生成文件存放在本插件的数据目录。链接后的运行库不会被插件写入；停用时释放捕获排除及宿主命令接管。原桌宠关闭时，独立宿主也随之关闭。

状态灯只有在窗口确认了 Windows 原生状态后才显示已生效。初次在运行中激活而窗口尚未连接时，会提示重新启动；不会冒充已经排除。

原生窗口验证范围见本节。已验证内容不等于逐一验证微信、QQ、Snipaste、PixPin 和 NVIDIA 的所有具体版本；NVIDIA 即时重放本身需要在你的运行环境中重新开启后复测。被旧保护模式关闭的即时重放不会由插件自动开启。
