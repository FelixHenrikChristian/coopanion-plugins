# Changelog

## 0.6.0

- Remove native-page patching, recovery utility, compatibility feed/helpers, native settings and prototype.
- Keep independent wardrobe panels, Lulu example, authoring guidance and standard appearance API behavior.
- Document verified legacy rollback before upgrading; the new release never writes host program files.
- Add Chinese discovery keywords. Market reinstatement remains subject to official review.

## 0.5.2

- Replace the default downloadable profile, preview artwork and bilingual authoring examples with Lulu: Orange with removable bird bag, Pajamas and Cardboard Dinosaur.
- Remove the previous character example and procedural artwork from the current source, preview and native-page prototype.
- Reuse four approved Lulu stills; the full animated figure remains a separate independently installable release.

## 0.5.1

- Support the checksum-reviewed native wardrobe page shipped with Coopanion 0.2.19 while retaining compatibility with 0.2.17.
- Recover safely after a reviewed host update: archive the previous private recovery record, preserve the new upstream page and back up that version before patching it.
- Preflight every owned helper before rollback; unknown pages and externally modified helpers remain protected. Preserve native saved looks, dialogs and unconfigured figures.

## 0.5.0

- Add bilingual topology-first white-background matting guidance and an optional offline Python helper, without adding generation jobs, downloads or dependencies to the World runtime.
- Separate border-connected background, enclosed gaps, protected light foreground and ambiguous regions; preserve original opaque RGB and record leakage warnings instead of assuming dark outlines are always closed.
- Document same-frame raw/alpha playback, white recomposition, real display-size/floor calibration, idle breathing, reusable expression anchors and reversible versioned delivery.
- Keep authoring requirements separate from actual production acceptance; no personal references, media, wardrobe profiles or deployment paths are bundled.

## 0.4.1

- Support optional embedded PNG/WebP thumbnails for outfits and individual options in both native and separate wardrobes.
- Keep previews local and bounded: 12 KiB per image and the existing 64 KiB total profile limit; reject remote URLs and non-raster payloads.

## 0.4.0

- Add an opt-in native wardrobe compatibility adapter for the checksum-verified desktop-pet 0.2.0 page: outfits followed by outfit-specific controls.
- Keep standard native appearance persistence, Coo/unconfigured figures, preview and import/removal flows.
- Back up before patching; restore on normal stop, recover interrupted installation and refuse overwriting external changes.
- Use an origin/token-checked, read-only loopback feed without weakening CSP or modifying figure resources.
- Document supported versions, explicit configuration, uninstall/recovery and the distinction from an official host API.
- Refresh bilingual project documentation and make the GitHub README English by default.

## 0.3.0

- Default to Chinese with a shared, persistent Chinese/English panel selector; preserve pending choices and JSON drafts when switching.
- Add a detailed bilingual manual with reference/motion prompts, raw video gates, temporal matting steps, figure runtime requirements and import troubleshooting.
- Add full field tables, complete fictional profiles and a downloadable JSON Schema.
- Add read-only configuration checks, local installed-ID inspection and example/manual downloads in the panel.
- Enforce the profile limit in UTF-8 bytes, including pasted input.

## 0.2.3

- Follow the host theme with a dotted preview stage, compact outfit cards and horizontal option rows.
- Show read-only thumbnails from the selected local figure pack, with origin/path and size restrictions.
- Add isolated preview-asset security tests and responsive layout verification.

## 0.1.1

- Set an explicit root width for flex-based World panel hosts.
- Verify the packaged panel against the actual Core extension service.

## 0.1.0

- Separate wardrobe panel with outfit-specific options mapped to existing figure schemes.
- Local profiles, validated resource combinations and write-ahead appearance recovery.
- Staged continuous-animation authoring guidance for people and agents.
- Fictional preview and isolated lifecycle tests, without runtime package dependencies.
