# 白底卡通抠像

这是离线制作配方，不是新增的 World 运行时能力。前提是连续原视频已经验收、背景近似均匀白色、角色有可辨识的绘制边界，并有检查过的粗前景先验。它不是适用于任意画面的万能去背算法。

## 判断顺序

1. 从原始 RGB 按源时序解码，不改尺寸、不各自裁边／居中，不使用已经锐化、重画过的旧抠图作为颜色来源。
2. 同时按亮度和通道色差识别近白候选。工具起始值为 uint8 RGB 最小通道235、最大通道差18；先看实际原片，再调整。白区采用四连通，避免对角线小缝串通。
3. 先去掉与画面边界连通的白区，检查它与旧前景内部的重叠。重叠较大可能是黑边缺口、旧蒙版不准，或浅色材质连到了外底；这是警告，不能直接断定哪一方正确。
4. 封闭白区另行检查：确认的奶油色皮毛、浅色布料、高光保留，确认的肢体间背景空隙去除。粗视频蒙版只是依据之一，不是真值。工具对中间重叠比例的区域保留并标注待查，不一律强删。
5. 确认真正串通时，提供正向保护蒙版阻断外底泛洪；封闭空隙则提供选择真实近白背景的负向标记。蒙版与原画布同尺寸，正负区域不得重叠；保护区不能跨过真正的背景空隙。按选用的视频工具传播修正，不重新逐帧生图。
6. 原片不透明像素保持不变，仅在真实深色边界旁很窄的、中性色抗锯齿边缘做解析去白混色。不补画替代黑线，也不默认逐帧重新估算整个人物颜色。
7. 透明素材保持源几何与时序，保留原视频、参数、工具哈希、修正与输出哈希。颜色去背并不自动保证时间连续，仍须播放验收后继续。

## 可选离线工具

`docs/tools/matte_connected_white.py` 提供确定性的 NumPy／OpenCV 实现及单帧命令行入口。它不会自动安装依赖、联网、扫描部署目录，也不会从 World 进程执行。审阅源码后，在项目独立环境使用 NumPy、OpenCV、Pillow；优先复用已有环境，新增安装要记录与可回退。工具本身不需要模型权重；粗蒙版的制作是另一独立步骤。

```sh
python docs/tools/matte_connected_white.py --image raw/000000.png --prior masks/000000.png --output alpha/v002/000000.png --report reviews/000000.json
```

修正时可附加 `--protect corrections/keep.png`、`--background corrections/remove.png`。两者为灰度图，零是不标记，非零是该修正区；RGB 输入及所有蒙版宽高一致。粗先验为 uint8 灰度，0是背景、255是前景。输出为新建的 straight alpha 无损 RGBA PNG，拒绝覆盖已有输出或源文件。单帧工具不负责视频解码、帧率、时间戳和播放验收。Python 的 `remove_white_background` 返回 RGBA、诊断统计、分类彩色预览，可由调用者接入受控的视频流程。

诊断区分外底、封闭背景、白色保护、不确定区域及外底与旧前景内部的冲突。较大或靠近衣物的警告需要复核／修正；警告数量小不证明画面合格，没有一个通用阈值能自动认证动作。

## 必须经过的播放关卡

用同一源时钟并排比较“原片／旧抠图／新抠图”，确保同帧。每条完整看原速与半速；循环动作还要在两种速度下各看真正循环子段及接缝至少三轮，不只是完整文件回放。检查深色、浅色、饱和色、棋盘格，并回贴白底比较原画黑线和浅色材质。不透明 RGB 相同，也仍可能因为 alpha 错误删掉布料，两个通道都要检查。

重点看手指、脸旁空隙、褶皱、新露出的内部空间、脚部轮廓及起步／停步。不要直接平均未对齐的运动蒙版来消闪，否则会糊掉手和布料；先修正不断变动的区域判断或错误保护先验。未看过／未解决的保持待验收，拼图、哈希、指标只是诊断，不是播放验收。

## 高效交付

先打通一个短动作，再批处理。保留合格原片、此前已接受版本和简短版本／重试记录；只留必要工作帧缓存、限制并行数，不重复下载模型、重生已合格视频或保存每帧诊断图。个人素材和配置不进入本公开包。可回退安装前核对帧数、尺寸、帧率／时序、哈希、原角色可见大小、脚底基线、表情 alpha 和运行时衔接。
