# 原生装扮页兼容集成 · 0.5.1

这是**默认关闭、显式启用的实验兼容补丁**，不是 Coopanion 正式提供的 World 插槽。独立衣橱与制作指导仍可照常使用。

## 效果

在原生「装扮」页选择已导入衣橱配置的角色后，完整搭配列表变成「服装 → 当前服装的部件」。缺少资源的组合禁用。无配置角色和 Coo 使用原有控件，预览、导入、删除及主题由原页面负责。

在这里点击搭配是普通原生装扮选择，由桌宠标准接口保存；停用扩展只恢复原页面布局，保留这次选择。独立衣橱面板的「应用」仍使用其外观恢复机制，两者不要同时操作。

## 支持版本

支持下列已检查的 Coopanion 版本所带 `cortico-world-desktop-pet@0.2.0` 页面，还必须匹配对应的 `web/dress.js` SHA-256：

```text
Coopanion 0.2.17: b594171051e90e4f368c635b4fd008405f6e41e6dfd3dbd907fdbffa767fbe9f
Coopanion 0.2.19: 87919223e6d26bdbcfc8bff7f1f51e5c5f52b51ceafd45a72b4f0f5b780b30af
```

仅版本号相同不代表兼容。文件校验不符时不会修补，不会自动扩大支持范围。

## 启用

1. 安装 0.5.1，按宿主要求重启 Core，保留已经导入的衣橱配置。
2. 打开「装扮工作室 → 配置」，填写 **desktop-pet 包的 web 绝对目录**。这是已安装 `cortico-world-desktop-pet` 下的 `web` 文件夹，不是角色素材目录。扩展不会搜索磁盘。
3. 开启 **原生装扮页兼容补丁**；默认本机端口 `17891`。冲突时可指定另一个 1024–65535 端口。保存后重启此 World。
4. 检查「原生页兼容」状态灯。成功后重新打开原生「装扮」页面；已经打开的页面可能仍缓存旧模块。
5. 检查服装切换、该服装的部件、缺失组合禁用和其他角色的原有功能。

修改路径或端口前，先停用 World 并确认回滚成功；修改配置后再启用并重新打开原生页。不要在补丁仍运行时移动安装目录或覆盖安装程序。

## 写入与通信范围

- 先在扩展自己的 `wardrobe-studio/native-adapter.json` 记录原始字节、校验值和恢复信息，再修改页面。此文件是私有本机记录，不要上传到公开仓库。
- 只临时修改 `web/dress.js` 的三个已检查位置，另写入三个 `wardrobe-studio-*.js` 辅助模块。不会改其他程序文件、角色 manifest 或动画素材。
- 开启一个仅监听 `127.0.0.1` 的**只读** WebSocket 接口，向原生页发送衣橱分组和语言。不提供命令、文件读取或外观写入 RPC。检查精确桌宠 Origin 和随机令牌；HTTP 路径一律返回 404。
- 不放宽宿主 CSP，不载入外网脚本，不安装依赖或模型。
- 提供方断开时回到原控件；异常失联由约 6.5 秒看门狗兜底。恢复连接后可以重新分组。配置内容变化不需要改写页面。

## 停用、卸载与恢复

正常停用先关闭只读接口，再按校验值恢复原始 `dress.js`，移除仍匹配本扩展校验值的辅助文件。重复停用是幂等的。重新打开原生页可确认恢复。最后再卸载扩展。

若程序被强制结束，磁盘补丁可能暂留；接口离线后，已经加载的原生页会使用原控件。下次启用会先恢复上次补丁，再重新安装。卸载前应正常停用并确认恢复，不能仅删除扩展目录。

若无法启动 Core，可先退出 Coopanion，使用已有 Node.js 执行已安装扩展包内的恢复工具：

```sh
node src/native-restore.js --data-dir "<World 的 dataDir>" --web-dir "<desktop-pet/web>"
```

`--data-dir` 是包含 `wardrobe-studio` 文件夹的父目录，不是该文件夹本身。工具只根据私有备份恢复已知原页，拒绝覆盖外部更新过的页面或删除外部修改的辅助文件。不要手动把未知文件当成原始备份。

宿主升级后若出现「外部修改／回滚拒绝」，先保留私有恢复记录并检查更新后的官方文件，再决定是否需要修复或重新安装宿主；不要盲目用旧文件覆盖新版本。关闭此兼容选项后仍可使用独立面板。

## 验证边界

宿主升级后，仅当新版原始页面的完整校验值也在已检查列表内，扩展才自动恢复接入：先把旧恢复记录归档到私有 `native-adapter-history` 目录，核对全部残留辅助模块的所有权，保留新版官方页面，再备份新版并应用兼容补丁。重复停用不会把新版降回旧页。未知页面或被外部修改的辅助模块仍阻止自动恢复，不会跳过安全校验。

发布前必须在临时目录测试备份、回滚、重复停止、崩溃后恢复、外部改动保护、文件名冲突、接口 Origin/令牌拒绝；再经本人授权检查真实原生窗口。无需生成或改写人物素材。此兼容实现会随宿主更新失效，不代表已存在通用的官方接口。
