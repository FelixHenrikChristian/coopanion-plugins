# coo家园实施范围与验收

这是已确认的目标范围。勾选项必须有代码和实际验收证据；中间版本不能缩小最终目标。

- [x] 首次提交只迁入已批准场景，并完整保留其已发布主线历史；验收后推送。
- [x] 场景模块化，保持美术与独立 HTML，支持 World 挂载、暂停和释放。
- [x] 独立 Figure API 2 实例，只读跟随用户当前选择的角色和服装，正确处理家具遮挡。
- [x] 室内与菜园可达路线、家具碰撞、动作队列、手动指令优先级、已有动作替代。
- [x] 32 个家具登记点的适当行为与状态反馈，不把装饰物描述为具有未实现的精细动作。
- [x] 独立家园生活状态与日常自主活动，支持取消、暂停和恢复。
- [x] 8 块菜畦、现有作物、生长阶段、播种、浇水、采收；30–90 分钟节奏，无金币系统。
- [x] 页面关闭后停止绘图、音频和细致寻路，以估算行程和活动时长继续规则模拟；完全退出后补算离线进度。
- [x] 自主 AI 计划提供独立开关、调用间隔和预算；规则活动不依赖每一步 AI 调用。
- [x] 家园人格、声音和模型服务沿用当前宿主设置，独立聊天历史和家园动作上下文。
- [x] 桌宠主会话可查询家园状态并安排家园任务；重要家园事件可以主动转达给桌宠，带去重和冷却。
- [x] 上述转达不控制原桌宠移动、换角或生活状态；家园完整聊天不自动混入主会话。
- [x] 独立存档子目录、原子写入、版本迁移、幂等结算和崩溃恢复。
- [x] 真实宿主隔离验收、双实例性能与清理验收、隐私与安装包检查。

## 实施阶段

1. **迁移**：导入树相等，原历史可达，只有场景目录变更；已验收并推送 `3616989`。
2. **接入基础**：批准场景直接进入 World；官方角色独立实例、选角观察、遮挡、四视图、容器布局与卸载。已通过浏览器与隔离正式宿主验收，见[证据与限制](coo-home-foundation.md)。
3. **生活闭环**：导航、家具状态、动作调度、自主规则、后台简化和存档。已通过中性角色与正式宿主隔离验收，范围见[生活与家具](coo-home-life.md)。
4. **种植闭环**：作物阶段、照料、收获、离线结算。八作物计时、实际浏览器五阶段、旧存档迁移与正式 Core 保存恢复已验收，见[种植规则与证据](coo-home-life.md)。
5. **认知与桌面桥**：独立家园模型请求、人格与声音复用、可配置 AI 自主计划、桌面双向工具与摘要汇报。已通过正式 Core、console 与官方 Figure 的隔离验收；实际桌面对话安排家园任务，实际采收完成后唤醒主会话并产生桌宠气泡，见[对话与桥接证据](coo-home-life.md#对话语音与整体回归alpha4)。
6. **整体验收**：真实 SDK 与认证适配、性能、兼容性、恢复、隐私和完整交付说明。已完成 116 项仓库单元测试、浏览器回归、双实例清理及实际压缩包独立提取验收；当前交付为 `0.4.0-alpha.4`，见[操作与交互说明](coo-home-life.md)。源码与本地包交付不包含 npm 或插件市场发布，也不改动用户正在使用的部署。

每阶段完成后运行对应检查和浏览器验收，通过后提交推送。若通用角色合成或宿主模型适配需要改变宿主、缩小角色兼容范围或改变已确认的产品行为，应先提交具体验证结果，再确认替代方案。

## 验收边界

- 模拟协议的测试不能替代真实 SDK 接入验收；仓库检查通过也不能证明画面遮挡正确。
- 场景清晰度以已批准版本为基准，优先减少无效绘制、蒙版刷新和资源滞留。
- 已安装角色的任何标识、描述、媒体和运行配置不进入源代码、提交、示例、公开截图或发布包。
- 只使用中性合成角色开展可提交的验收；所有实际部署状态留在本机，场景截图默认不显示个人角色。
- 代码与场景保持单一来源，正式包不携带开发部署、测试资产或宿主运行库。
- 二维角色融入三维场景以位置合理、动作可理解、遮挡大体正确为准，不追求精细姿态贴合；尽量保留场景，只增加必要的交互状态。
