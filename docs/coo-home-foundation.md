# coo家园基础接入验收

本文记录 `alpha.1` 基础接入阶段：把已批准的雨夜街区接入 World 页面，并验证角色合成与生命周期。以下限制和观测对应当时版本；当前生活、种菜、聊天与三个原生页面的说明见[操作与交互](coo-home-life.md)。

## 实现边界

- 场景只维护在 `scenes/amane-mart/src`。独立 HTML 与 World 前端均由同一份代码构建。
- 家园使用单独的官方 Figure API 2 沙箱实例，通过只读观察连接跟随已选角色与服装；动作消息只发给家园 iframe。
- 角色置于三维位置，通过本地场景深度蒙版处理屋顶、墙与家具遮挡。角色仍使用原包的二维绘制方式，没有生成或导出私人角色图像。
- 可见页面限制为最高 60 FPS，角色最高 30 FPS；页面隐藏时停止绘制。卸载时释放帧循环、连接、iframe 和 Three.js 资源，并等待在途蒙版读取结束。不降低场景分辨率或材质质量。
- 本阶段只提供场景浏览、角色显示、物件识别与测试用姿态入口。尚无生活模拟、种植进度、聊天、声音播放或桌面汇报。

## 自动验收

后端测试使用临时配置和中性形象目录，覆盖本机服务发现、只读观察、衣装更新、快速切换、断线重连、资源清理和无桌面写控制。浏览器测试加载实际构建产物、实际场景和自行绘制的 Figure API 2 协议夹具。

| 检查 | 已观测结果 |
| --- | --- |
| 场景目录 | 32 个家具点与 8 块菜畦，共 40 项 |
| 四视图 | 完整外观、全部墙面、自动剖墙、无墙俯览均正确切换 |
| 屋顶遮挡 | 合成角色露天可见，屋顶下不可见，剖墙后重新可见 |
| 家具遮挡 | 柜前可见、柜后不可见；推车能遮住角色的部分身体 |
| 角色切换 | 角色、服装和快速连续切换后，三维位置保持 |
| 原角色隔离 | 哨兵实例未收到家园动作；没有桌宠写控制请求 |
| 隐藏与恢复 | 已挂载面板隐藏后，场景与角色帧数停止；显示后继续 |
| 绘制上限 | 本机 1440×768、DPR 1 窗口采样 5.0085 秒绘制 301 帧，约 60.10 FPS；上限回归检查通过，未降低画质 |
| 挂卸 | 连续三次挂载、卸载后，无旧帧、流连接或页面错误残留 |
| 独立 HTML | 与迁入版本同相机截图近乎一致；小差异局限于动态路面反射 |

测试输出写入 Git 忽略的 `scratch/coo-home-browser`。公开代码与归档不包含测试截图、临时部署或用户角色素材。

浏览器验收命令：

```sh
npm run build --workspace=cortico-world-coo-home
node packages/cortico-world-coo-home/test/browser-smoke.mjs
```

未安装 Playwright 或浏览器时，通过 `COO_HOME_PLAYWRIGHT_MODULE`、`COO_HOME_BROWSER` 指定本机工具位置；这些值不写入源代码。`--software` 可用于软件渲染兼容检查。

## 正式宿主隔离验收

已使用 Coopanion `0.2.20` 的未修改 Core、官方 console、正式 desktop-pet 服务、官方 Figure frame 与 `kit.createBody` 进行集成验收。测试生成单独的部署目录和中性几何角色，未读取或修改正在使用的部署。

- World 出现在正式 WebUI 清单，官方页面加载实际构建 bundle 与独立角色。
- 正式 `status`、流连接、角色与服装更新正常；原测试桌宠连接保持，未被家园观察连接抢占。
- 中性 kit 角色的脚底位置连续多帧稳定；浏览器没有页面错误。
- 停用、重启桌宠服务后自动重连；停用家园后关闭流，重新启用可以继续使用。
- 通过浏览器正常的 `local-network-access` 权限授权访问隔离的本机角色服务，没有禁用浏览器安全机制。

复现时设置 `COOPANION_APP_ROOT` 为本机安装的 `resources/app` 目录，并设置上述两个浏览器工具环境变量，然后运行：

```sh
node packages/cortico-world-coo-home/scripts/host-smoke.mjs
```

不提供浏览器工具变量时，该脚本只验证正式 Core 与接口，不把它计为页面渲染验收。临时部署在退出时清理，脚本不修改本机正在运行的 Coopanion。

## 基础阶段的限制

- 图形渲染速度取决于宿主 GPU 和窗口尺寸，协议测试不能代替目标设备的性能测试。
- 深度蒙版以有限频率更新，近景斜边有轻微锯齿。动态家具和连续行走将在后续阶段结合场景变化继续验收。
- 宿主没有正式的跨 World 随机端口发现接口；桌宠服务配置为端口 `0` 时暂无法自动连接。默认端口和官方固定端口回退范围可用。
- 身体动作以当前包实际支持的词汇为准。示例坐姿通过不代表所有角色包都具备睡觉、做饭等专用动画。
